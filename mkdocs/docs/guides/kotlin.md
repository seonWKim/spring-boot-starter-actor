# Kotlin

The `actor-kotlin` module adds a thin Kotlin layer over the Java API: `suspend` functions instead of
`CompletionStage`, reified type parameters instead of `Class` arguments, and `kotlin.time.Duration`
timeouts. Each function calls the Java API, so everything in the other guides applies unchanged.

## Installation

Add `actor-kotlin` next to the starter. It brings `kotlinx-coroutines-core`; Spring Boot manages its
version.

```kotlin
dependencies {
    implementation("io.github.seonwkim:actor-spring-boot-starter:1.0.0")
    implementation("io.github.seonwkim:actor-kotlin:1.0.0")
}
```

The module is compiled with Kotlin 1.9.25, the version Spring Boot 3.5 manages, so applications on that
version or later can use it.

### Null safety

`actor-api` declares its nullability: values are non-null unless marked `@Nullable` (for example
`AskCommand.getReplyTo()`). Kotlin turns those annotations into Kotlin types with the
`-Xjsr305=strict` compiler flag, which projects generated by start.spring.io already set:

```kotlin
kotlin {
    compilerOptions {
        freeCompilerArgs.addAll("-Xjsr305=strict")
    }
}
```

Without the flag, Kotlin only warns, and the API's types are platform types (`String!`).

## Defining an actor

`actorBehavior<Command>(actorContext)` is `SpringActorBehavior.builder(Command::class.java, actorContext)`.
Commands are often a sealed interface:

```kotlin
@Component
class HelloActor : SpringActor<HelloActor.Command> {
    sealed interface Command

    class SayHello : AskCommand<String>(), Command

    override fun create(actorContext: SpringActorContext): SpringActorBehavior<Command> =
        actorBehavior<Command>(actorContext)
            .onMessage(SayHello::class.java) { ctx, msg ->
                msg.reply("Hello from actor ${actorContext.actorId()}")
                SpringActorBehavior.same()
            }.build()
}
```

## Spawning and finding actors

The reified helpers take the actor type as a type argument. Kotlin can't infer the command type from
the actor type by itself, so pass `_` for it:

```kotlin
// actorSystem.actor(HelloActor::class.java)
val builder = actorSystem.actor<HelloActor, _>()

// Suspends until the actor runs
val hello: SpringActorHandle<HelloActor.Command> =
    actorSystem.actor<HelloActor, _>().withId("hello").withTimeout(5.seconds).awaitSpawn()

val running = actorSystem.awaitGetOrSpawn<HelloActor, _>("hello") // spawn when none runs
val maybe = actorSystem.awaitGet<HelloActor, _>("hello")          // null when none runs
val exists = actorSystem.awaitExists<HelloActor, _>("hello")

// Sharded actors (cluster mode)
val counter = actorSystem.sharded<CounterActor, _>().withId("counter-1").get()
```

| Kotlin | Java API it calls |
|---|---|
| `actor<A, _>()` | `actor(A.class)` |
| `sharded<A, _>()` | `sharded(A.class)` |
| `awaitGetOrSpawn<A, _>(id)`, `awaitGet<A, _>(id)`, `awaitExists<A, _>(id)` | `getOrSpawn`, `find` (as a nullable), `exists` with `A.class` |
| `builder.awaitSpawn()`, `builder.awaitGetOrSpawn()` | `spawn()`, `getOrSpawn()` on the spawn builder |
| `actorBehavior<C>(actorContext)` | `SpringActorBehavior.builder(C.class, actorContext)` |
| `handle.child<A, _>()`, `handle.child<A, _>(id)` | `child(A.class)`, `child(A.class, id)` |
| `awaitSpawn()`, `awaitGetOrSpawn()`, `awaitGet()`, `awaitExists()` on a child builder or reference | `spawn()`, `getOrSpawn()`, `get()`, `exists()` |
| `withTimeout(5.seconds)`, `withLimit(10, 1.minutes)`, `startSingleTimer(key, msg, 30.seconds)`, `startTimerAtFixedRate(key, msg, 10.seconds)` | the same methods with a `java.time.Duration` |
| `unwrap<X>()` on the actor system, a ref or a behavior context | `unwrap(X.class)` |

## Child actors

`handle.child<A, _>()` is the child builder and `handle.child<A, _>(id)` the lookup reference of
[Child actors](core/actors.md#child-actors). Outside the parent, the `await*` functions suspend until the
operation completes. A child lookup returns `null` when the child doesn't run:

```kotlin
// In a suspend function, with the parent's handle
val worker = dispatcher.child<WorkerActor, _>()
    .withId("worker-1")
    .withSupervisionStrategy(SupervisionStrategy.restart().withLimit(10, 1.minutes))
    .withTimeout(5.seconds)
    .awaitGetOrSpawn()

val found: SpringActorHandle<WorkerActor.Command>? = dispatcher.child<WorkerActor, _>("worker-1").awaitGet()
val running: Boolean = dispatcher.child<WorkerActor, _>("worker-1").awaitExists()
```

Inside the parent's own handlers, don't wait: pass `spawn()` or `getOrSpawn()` to `pipeToSelf`, as in
[Spawning children from inside the parent](core/actors.md#spawning-children-from-inside-the-parent).

## Durations

These methods also take a `kotlin.time.Duration`: `withTimeout` on the spawn, sharded, child and ask
builders and on the child reference, `SupervisionStrategy.restart().withLimit`, and the timers on the
behavior context:

```kotlin
ctx.startSingleTimer("idle", IdleTimeout, 30.minutes)
ctx.startTimerAtFixedRate("flush", Flush, 10.seconds)
```

## Asking

`awaitAsk` sends an `AskCommand` and suspends until the reply arrives. Without a timeout, the handle's
default timeout (3 seconds) applies.

```kotlin
val greeting: String = hello.awaitAsk(HelloActor.SayHello(), timeout = 2.seconds)
```

When no reply arrives in time, `awaitAsk` throws `java.util.concurrent.TimeoutException`. For a fallback
value instead, use the ask builder and finish it with `await()`:

```kotlin
val greeting = hello.ask(HelloActor.SayHello())
    .withTimeout(2.seconds)
    .onTimeout { "no answer" }
    .await()
```

`awaitAsk` works the same on a sharded actor handle. Cancelling the coroutine stops the wait; the
command has already been sent.

## In a WebFlux controller

With `kotlinx-coroutines-reactor` and `kotlin-reflect` on the classpath, WebFlux runs `suspend` handler functions:

```kotlin
@RestController
class HelloController(private val actorSystem: SpringActorSystem) {
    @GetMapping("/hello")
    suspend fun hello(): String =
        actorSystem.awaitGetOrSpawn<HelloActor, _>("hello-actor")
            .awaitAsk(HelloActor.SayHello(), timeout = 3.seconds)
}
```
