# AGENTS.md

Guide for AI agents working on spring-boot-starter-actor: a Spring Boot starter for Pekko typed actors.
`CLAUDE.md` is a symlink to this file.

## Module layout

- `core/`: the starter for Spring Boot 2.7 (`spring-boot-starter-actor`). All library code and tests live here.
- `core-boot3/`: the Spring Boot 3 starter (`spring-boot-starter-actor_3`). Its `src/` is generated from `core/` (javax → jakarta) and git-ignored; only `build.gradle.kts` is hand-written.
- `metrics/`: experimental ByteBuddy instrumentation with Micrometer.
- `example/`: runnable example apps, one Gradle module each (listed in `settings.gradle.kts`).
- `mkdocs/`: the docs site (`mkdocs/mkdocs.yml`, pages in `mkdocs/docs/`, build hooks in `mkdocs/hooks/`).
- `scripts/docs/`: docs tooling and its tests. `roadmap/`: the roadmap.

## Build and test

- Core tests: `./gradlew :core:test`
- Boot 3 tests: `./gradlew :core-boot3:syncAllBoot3Sources` then `./gradlew :core-boot3:test`
- Metrics tests: `./gradlew :metrics:test`
- Everything, in order: `./gradlew runTest` (or `make test`)
- Format: `./gradlew spotlessApply`; `./gradlew build` fails on `spotlessCheck`
- Docs tooling tests: `scripts/docs/test.sh`; llms.txt link check: `scripts/docs/check_llms_links.py`
- Docs site: `mkdocs build --config-file mkdocs/mkdocs.yml` (Python deps in `mkdocs/requirements.txt`)

## Rules

- **Boot 2/3 sync:** change `core/` only, then run `:core-boot3:syncAllBoot3Sources` and both test suites. Code must compile on Boot 2 (javax) and on Boot 3 after the javax → jakarta rewrite.
- **Java 11 baseline:** library modules target Java 11. No newer language features or APIs in `core/` or `metrics/`; examples may use newer Java.
- **Public API ships complete:** a new or changed public API comes with a test in `core/src/test`, a guide page in `mkdocs/docs/guides/` (added to `nav` in `mkdocs/mkdocs.yml` and to `mkdocs/docs/llms.txt`), and an example under `example/`.
- **Code style:** Palantir Java Format through Spotless. NullAway checks `io.github.seonwkim` in library code; mark nullable values with `@Nullable` (`javax.annotation.Nullable`). Follow the patterns in `mkdocs/docs/contributing/spring-conventions.md`.
- **Versions:** the project version lives in `gradle.properties`; dependency versions live in `gradle.properties` and the module `build.gradle.kts` files.

## Never

- Never edit `core-boot3/src/` by hand: it is generated from `core/` by `syncAllBoot3Sources` and overwritten on every sync.
- Never commit `mkdocs/site/` or `llms-full.txt`: the docs build writes them.
- Never raise the Java baseline or bump Spring Boot / Pekko versions as a side effect of another change.
- Never rewrite existing guide prose when a change only needs a new section.

## Where docs live

- User docs: `mkdocs/docs/` (getting started, `guides/`, `examples/`, `contributing/`), published to https://seonwkim.github.io/spring-boot-starter-actor/
- AI assistant index: `mkdocs/docs/llms.txt`; `llms-full.txt` is generated by `mkdocs/hooks/llms_full.py`
- Design proposals: `mkdocs/docs/contributing/rfcs/`. Roadmap: `roadmap/ROADMAP.md`. Overview: `README.md`
